# 3. Design direction

Status: Proposed as of this commit; it merges only once approved on its rendered phone and desktop views.

## Decision

**Custody Ledger**: Signal Ledger gives a security or analytics team a local, offline-first record of each evidence item, with the chain of custody written down so the record holds up.

Tagline: Every item logged, every hand recorded, nothing leaves this device.

## Why

The brand kit (`brand/BRAND.md`, `brand/tokens.css`, `brand/logo/`) sets the colours, type and voice every page uses, checked for contrast before any page is written.
